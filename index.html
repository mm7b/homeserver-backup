homeserver-backup

A personal backup script for one home media server.

This is a small private utility, run by its author on a single machine at home. Once a night it collects the configuration files of that server — settings, application databases, credentials — packs them into one archive, encrypts the archive, and uploads it to the author's own Google Drive so the server can be rebuilt if its disk fails.

Uploading is done with rclone, which is why this project has a Google OAuth client at all. The client is used by one person, to write files into that one person's own Drive.

What it touches

  • A single folder in the owner's Google Drive, holding the encrypted archives.
  • Nothing else: no other Google service, no other account, no other person's data.

Who it is for

Nobody but its author. It is published here only because Google requires an OAuth application to have a home page and a privacy policy, which you can read on the privacy page.
